CSS Styling and Layout

Learn how to style web pages, organize content, create layouts, and build responsive websites using Cascading Style Sheets.

Web Development CSS Fundamentals Responsive Design
01

Lesson Overview

CSS, or Cascading Style Sheets, is a language used to control the appearance and layout of HTML documents. It allows developers to design attractive, organized, and user-friendly websites.

In this lesson, students will explore CSS fundamentals, selectors, properties, the box model, layout techniques, Flexbox, Grid, responsive design, and other styling techniques used in modern web development.

Key Concept: HTML provides the structure of a webpage, while CSS controls how that structure looks and is arranged.
02

Learning Objectives

At the end of this lesson, students should be able to:

  • Define CSS and explain its role in web development.
  • Identify the different ways of applying CSS to HTML.
  • Use CSS selectors and properties correctly.
  • Explain the CSS box model.
  • Apply colors, typography, borders, and backgrounds.
  • Use Flexbox and CSS Grid to organize webpage layouts.
  • Create responsive layouts using media queries.
  • Apply good practices when writing CSS code.

Introduction to CSS

Websites are made up of different elements such as headings, paragraphs, images, links, buttons, and forms. HTML organizes these elements, but it does not provide complete control over their visual appearance.

CSS makes it possible to change the colors, fonts, spacing, alignment, borders, and overall presentation of a webpage.

04

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language that describes how HTML elements should be displayed on a screen, paper, or other media.

The word "cascading" refers to the rules used by browsers to determine which styles should be applied when multiple CSS rules affect the same element.

CSS separates the content of a website from its visual presentation. This makes websites easier to maintain and update.
05

Importance of CSS in Web Development

CSS plays an important role in creating modern websites. It improves the visual quality and usability of webpages.

Visual Design

CSS adds colors, fonts, borders, shadows, and other visual effects.

Organization

It arranges webpage elements into clear and structured layouts.

Consistency

A single stylesheet can provide a consistent design across multiple pages.

Responsiveness

CSS helps websites adapt to different screen sizes and devices.

06

CSS Syntax

A CSS rule consists of a selector and a declaration block. The selector identifies the HTML element to style, while the declarations define the styles.

h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}

Selector: h1 identifies the heading.

Property: color and font-size describe what will change.

Value: blue and 32px specify the style.

07

Types of CSS

There are three common ways to apply CSS to an HTML document.

1. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute.

<p style="color: blue;">
    This is a blue paragraph.
</p>

2. Internal CSS

Internal CSS is placed inside a style element in the HTML document's head section.

<style>
    p {
        color: green;
        font-size: 18px;
    }
</style>

3. External CSS

External CSS is written in a separate .css file and connected to an HTML document using the link element.

<link rel="stylesheet" href="style.css">
Recommended: External CSS is commonly used for larger projects because it keeps HTML and CSS organized in separate files.

Cascade and Specificity

The cascade determines how the browser applies CSS rules when more than one rule targets the same element.

Specificity is the system used to determine which selector has greater priority.

  • Inline styles generally have higher priority than selector-based rules.
  • ID selectors have greater specificity than class selectors.
  • Class selectors have greater specificity than element selectors.
  • When specificity is equal, the later applicable rule generally takes precedence.
p {
    color: black;
}

.message {
    color: blue;
}

#notice {
    color: red;
}

CSS Typography

Typography refers to the style and appearance of text. CSS provides properties that help improve readability and create visual hierarchy.

  • font-family – specifies the typeface.
  • font-size – controls the size of text.
  • font-weight – controls the thickness of text.
  • font-style – changes text style, such as italic.
  • text-align – aligns text horizontally.
  • line-height – controls the space between lines.
  • text-decoration – adds or removes text decoration.
p {
    font-family: Arial, sans-serif;
    font-size: 18px;
    line-height: 1.6;
    text-align: justify;
}

The CSS Box Model

The CSS box model describes how every HTML element is represented as a rectangular box. It consists of four main areas: content, padding, border, and margin.

Margin
Border
Padding
Content
  • Content: The actual text, image, or other content.
  • Padding: Space between content and border.
  • Border: The line surrounding the padding and content.
  • Margin: Space outside the border.

Margin and Padding

Margin and padding control spacing around webpage elements, but they serve different purposes.

Margin creates space outside an element's border. Padding creates space inside the border, between the content and the border.

.card {
    margin: 20px;
    padding: 25px;
}

CSS Display Property

The display property determines how an element is displayed and how it participates in the webpage layout.

  • Block: Starts on a new line and generally takes the available width.
  • Inline: Appears within the same line and uses only the required space.
  • Inline-block: Appears inline while allowing width and height.
  • None: Hides the element and removes it from the layout.
  • Flex: Creates a flexible layout container.
  • Grid: Creates a grid-based layout container.
.navigation {
    display: flex;
    gap: 20px;
}

CSS Flexbox

Flexbox, or Flexible Box Layout, is a CSS layout model designed to arrange elements in one dimension: either a row or a column.

It is useful for navigation bars, card arrangements, centered content, and flexible page sections.

Flexbox Layout Illustration

Item 1
Item 2
Item 3
Three items arranged in a horizontal row. 
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
    flex-wrap: wrap;
}

Common Flexbox Properties

  • flex-direction – defines row or column direction.
  • justify-content – aligns items along the main axis.
  • align-items – aligns items along the cross axis.
  • flex-wrap – controls whether items wrap.
  • gap – adds spacing between items.

Responsive Web Design

Responsive web design is an approach that allows a website to adjust its layout and content based on the screen size and device being used.

A responsive website should be usable on desktop computers, laptops, tablets, and smartphones.

21

CSS Media Queries

Media queries allow CSS rules to be applied only when certain device or viewport conditions are met.

/* Small screens */
@media (max-width: 600px) {
    .container {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 26px;
    }
}

/* Larger screens */
@media (min-width: 900px) {
    .container {
        grid-template-columns: repeat(3, 1fr);
    }
}
Media queries help developers create layouts that adapt to different screen widths.

Bootstrap

A utility-first framework that provides small classes for building custom designs.

23

CSS Transitions and Effects

CSS transitions allow property changes to happen gradually over a specified duration. They can make interactions feel smoother.

.button {
    background-color: #10569a;
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: #082d59;
}

Other visual effects include transforms, shadows, opacity changes, and CSS animations.

24

CSS and Web Accessibility

Accessibility means designing websites so that people with different abilities can use them. CSS can support accessibility when used carefully.

  • Maintain sufficient contrast between text and backgrounds.
  • Use readable font sizes.
  • Make interactive elements easy to identify.
  • Do not communicate important information through color alone.
  • Keep focus indicators visible for keyboard users.
  • Avoid animations that may cause discomfort.
25

CSS Best Practices

Following good CSS practices helps keep stylesheets organized, readable, and easier to maintain.

  1. Use meaningful class names.
  2. Keep HTML and CSS in separate files when appropriate.
  3. Organize related styles together.
  4. Avoid unnecessary duplicate rules.
  5. Use reusable classes.
  6. Make layouts responsive.
  7. Test styles in different browsers.
  8. Use comments to explain complex sections.
/* Main content container */
.main-container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 20px;
}

Lesson Summary

CSS is an essential technology in web development because it controls the presentation and layout of HTML documents. It provides tools for styling text, colors, backgrounds, spacing, borders, and page structures.

Through CSS selectors, the box model, Flexbox, Grid, and media queries, developers can create attractive and responsive websites. Understanding CSS fundamentals helps students build organized, accessible, and user-friendly webpages.

Remember: HTML builds the structure, CSS styles the presentation, and JavaScript adds interactivity.

Glossary of Terms

CSS
Cascading Style Sheets, a language used to style HTML documents.
Selector
A pattern used to target HTML elements for styling.
Property
The style characteristic being changed.
Value
The setting assigned to a CSS property.
Specificity
A method browsers use to determine which CSS rule has priority.
Box Model
The CSS model consisting of content, padding, border, and margin.
Flexbox
A one-dimensional CSS layout system.
CSS Grid
A two-dimensional CSS layout system using rows and columns.
Media Query
A CSS feature that applies styles based on device or viewport conditions.
Responsive Design
An approach that allows websites to adapt to different screen sizes.
Framework
A collection of reusable styles and tools for building interfaces.
Viewport
The visible area of a webpage in a browser window.
