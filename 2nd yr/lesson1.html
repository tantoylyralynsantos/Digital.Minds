SECOND YEAR • LESSON 01

Computer System Platforms and Architecture

Understand the components, platforms, architecture, and operation of computer systems in modern technology.

Introduction

"Technology is best when it brings people together." — Matt Mullenweg

Technology has become a vital part of everyday life. People use computers for communication, education, entertainment, business, research, and many other activities. Whether using a smartphone to send messages, a laptop to complete school assignments, or an online platform to attend virtual meetings, computer systems play an important role in modern society.

Computers have transformed the way individuals and organizations perform tasks. Schools use computers to provide learning materials and support collaboration. Businesses use computer systems to manage records, process transactions, and communicate with customers. Hospitals and government agencies also depend on computers to manage information and deliver services.

Computer System Platforms and Architecture focuses on the design, structure, and operation of computer systems. It examines the hardware and software components that make computer systems function effectively. It also explores the different platforms that support applications and explains how computer hardware is organized to process information.

A computer system platform consists of hardware, operating systems, and supporting software that allow applications to run. Computer architecture describes how the components are organized and how they interact to perform operations.

Key Idea

Understanding computer platforms and architecture helps learners understand how computers process, store, and manage information.

Learning Objectives

At the end of this lesson, students should be able to:

  • Explain the meaning and importance of computer systems.
  • Identify the basic functions and major components of a computer.
  • Differentiate hardware, software, and peopleware.
  • Describe different computer system platforms.
  • Explain the evolution of computer generations.
  • Identify the major functional units of computer architecture.
  • Describe the functions of the CPU, memory, input, output, and storage devices.
  • Explain the Von Neumann Architecture and its operation.
  • Recognize the functions of an operating system.
  • Discuss modern trends in computer systems.

1. Computer Systems

A computer system uses electronic components to process information.

A computer system is an electronic system that accepts data, processes it according to instructions, stores information, and produces meaningful output.

Computer systems are used in different environments, including schools, offices, businesses, hospitals, industries, and homes. They help users perform tasks more accurately and efficiently.

Examples of Computer Systems

  • Desktop computers and laptops
  • Smartphones and tablets
  • Servers and workstations
  • Embedded systems in appliances and vehicles
  • Supercomputers used for scientific research

3. Major Components of a Computer System

A computer system is composed of different elements that work together to perform computing tasks.

Hardware

The physical parts of a computer that can be seen and touched.

Software

Programs and instructions that tell the computer what to do.

Peopleware

The people who use, operate, maintain, and develop computer systems.

Remember

Hardware, software, and peopleware work together. A computer system needs both physical components and programs, as well as people who know how to operate and manage them.

4. Computer Hardware

Hardware refers to the physical components of a computer system. These components perform input, processing, output, and storage operations.

Input Hardware

Keyboard, mouse, scanner, microphone, and webcam.

Processing Hardware

CPU, motherboard, and graphics processing unit.

Output Hardware

Monitor, printer, speakers, and projector.

Storage Hardware

Hard disk drive, solid-state drive, flash drive, and memory card.

5. Computer Software

Software refers to the programs, instructions, and applications that control computer operations. Unlike hardware, software cannot be physically touched.

System Software

Manages computer hardware and provides a platform for application software.

Examples: Windows, Linux, macOS, and device drivers.

Application Software

Helps users perform specific tasks such as writing documents, browsing, designing, and communicating.

Examples: Microsoft Word, Google Chrome, and Photoshop.

Utility Software

Helps maintain, protect, and improve computer system performance.

Examples: Antivirus programs, backup tools, and disk cleanup utilities.

6. Peopleware

Peopleware refers to the individuals who interact with and manage computer systems. They are responsible for using, developing, maintaining, and supporting technology.

End Users

People who use computers to complete everyday tasks.

Programmers

Develop software applications and computer programs.

System Administrators

Manage computer systems, networks, and servers.

IT Support Specialists

Help users troubleshoot hardware and software problems.

Importance of Peopleware

Skilled professionals are necessary for developing software, managing hardware, solving technical problems, and ensuring that computer systems operate effectively.

7. Computer System Platforms

A computer system platform is the environment in which software applications run. Platforms consist of hardware, operating systems, and supporting software that provide services for users and applications.

Different platforms are designed to meet different computing needs. Some are intended for personal use, while others support businesses, organizations, and large-scale networks.

8. Desktop Platforms

Desktop platforms are designed for personal and professional computing tasks. They usually provide high processing power, large storage capacity, and support for multiple applications.

Microsoft Windows

A widely used desktop operating system for personal and business computers.

macOS

Apple's operating system designed for Mac computers.

Linux

An open-source operating system used on desktops, servers, and other devices.

Common Uses

  • Office work and document preparation
  • Research and online learning
  • Software development
  • Gaming and graphic design

9. Mobile Platforms

Mobile platforms are designed for devices that can be easily carried and used in different locations. They support wireless connectivity, touchscreen interfaces, and battery-powered operation.

Android

A mobile operating system used by smartphones, tablets, and other smart devices.

iOS

Apple's mobile operating system used on iPhone devices.

Common Uses of Mobile Platforms

  • Communication and social networking
  • Mobile banking and online shopping
  • Online learning
  • Navigation and entertainment

10. Server Platforms

Server platforms provide services and resources to other computers connected through a network. Unlike desktop computers, servers are designed to support many users simultaneously and operate continuously for long periods.

Windows Server

A Microsoft server operating system used to manage network resources and services.

Ubuntu Server

A Linux-based server platform used for hosting and managing services.

Red Hat Enterprise Linux

An enterprise Linux platform used in business and data center environments.

Functions of Server Platforms

  • File storage and sharing
  • Database management
  • Website hosting
  • Email services
  • Network management

11. Evolution of Computer Generations

Computer technology has progressed significantly over the years. Early computers were large, expensive, and limited in their capabilities. As technology advanced, computers became faster, smaller, more affordable, and more powerful.

FIRST GENERATION

Vacuum Tubes

First-generation computers used vacuum tubes as their primary electronic components.

  • Extremely large in size
  • Required significant electrical power
  • Produced large amounts of heat
  • Expensive to operate

Examples: ENIAC and UNIVAC I.

SECOND GENERATION

Transistors

Transistors replaced vacuum tubes, making computers smaller, faster, and more reliable.

  • Smaller physical size
  • Lower power consumption
  • Faster operation
  • Greater reliability
THIRD GENERATION

Integrated Circuits

Integrated circuits combined multiple electronic components onto a single chip.

  • Increased processing speed
  • Improved reliability
  • Reduced maintenance costs
  • Smaller physical dimensions
FOURTH GENERATION

Microprocessors

The fourth generation began with the invention of the microprocessor, which combines essential CPU functions into a single chip.

  • Personal computers became common
  • Significant performance improvements
  • Reduced cost
  • Increased portability
FIFTH GENERATION

Artificial Intelligence and Advanced Computing

Fifth-generation computing focuses on advanced technologies designed to make computers more intelligent and efficient.

  • Artificial Intelligence (AI)
  • Machine Learning
  • Robotics
  • Natural Language Processing
  • Quantum Computing

12. Introduction to Computer Architecture

Computer architecture refers to the design, structure, and organization of a computer system. It describes how hardware components are arranged and how they work together to process information.

Computer architecture serves as the blueprint of a computer system. It determines how instructions are executed, how memory is organized, how data is transferred, and how system performance can be optimized.

Importance of Computer Architecture

  • Performance: Improves processing speed and responsiveness.
  • Reliability: Supports stable operation and reduces errors.
  • Scalability: Allows systems to be upgraded and expanded.
  • Efficiency: Helps use memory and storage resources effectively.
  • Security: Supports protection of data and system resources.

13. Central Processing Unit (CPU)

The Central Processing Unit (CPU) is often called the brain of the computer. It executes instructions, performs calculations, and controls the activities of other computer components.

Arithmetic Logic Unit (ALU)

Performs arithmetic operations such as addition and subtraction, as well as logical comparisons.

Control Unit (CU)

Directs and coordinates the operations of computer components.

Registers

Small, high-speed storage locations inside the CPU that temporarily hold data and instructions.

Cache Memory

High-speed memory that stores frequently accessed data and instructions for faster processing.

14. Memory Systems

Computer memory stores data and instructions that the CPU needs while performing tasks. Memory can be classified into primary memory and secondary storage.

Random Access Memory (RAM)

RAM temporarily stores data and programs currently being used by the computer. It is volatile, meaning its contents are lost when power is turned off.

Read-Only Memory (ROM)

ROM stores important instructions needed for computer startup. It is non-volatile, meaning it retains information without power.

Cache Memory

Cache is a small, high-speed memory that helps the CPU access frequently used data quickly.

Memory Type Purpose Volatility
RAM Temporarily stores active data and programs Volatile
ROM Stores startup instructions Non-volatile
Cache Provides faster access to frequently used data Volatile

15. Input and Output Systems

Input and output devices allow users to communicate with a computer system. Input devices send data to the computer, while output devices present the results of processing.

Input Devices

Devices used to enter data and instructions into a computer.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam

Output Devices

Devices that present processed information to the user.

  • Monitor
  • Printer
  • Speakers
  • Projector
  • Headphones

16. Storage Systems

Storage devices keep data, applications, and files for future use. Storage capacity and speed are important factors affecting computer performance.

Hard Disk Drive (HDD)

Stores data using magnetic technology. It offers high storage capacity at an affordable cost but is generally slower than an SSD.

Solid-State Drive (SSD)

Uses flash memory technology. It provides faster performance, improved durability, and quicker boot times.

Flash Drives

Small portable storage devices used for transferring files, sharing documents, and backing up information.

Memory Cards

Compact storage devices commonly used in cameras, smartphones, and tablets.

Cloud Storage

Allows users to store files on remote servers and access them through the Internet.

Examples: Google Drive, OneDrive, and Dropbox.

17. Data Representation in Computer Systems

Computers represent and process information using number systems. Digital computers use binary because electronic circuits operate using two basic states.

Binary Number System

Uses only two digits: 0 and 1.

Decimal Number System

Uses ten digits: 0 through 9.

Hexadecimal Number System

Uses sixteen symbols: 0–9 and A–F.

Data Units

A bit is a single binary digit. Eight bits make one byte. Larger units include kilobytes, megabytes, gigabytes, and terabytes.

Example

The binary number 1010 represents the decimal number 10.

18. Von Neumann Architecture

The Von Neumann Architecture is one of the most widely used models for computer design. In this architecture, both instructions and data are stored in the same memory.

INPUT UNIT

Receives data and instructions

↓

MEMORY UNIT

Stores data and instructions

↕

CPU

Control Unit • ALU • Registers

↓

OUTPUT UNIT

Displays processed information

Simplified representation of the Von Neumann computer architecture.

Fetch-Decode-Execute Cycle

1. Fetch

The CPU retrieves an instruction from memory.

2. Decode

The Control Unit interprets the instruction.

3. Execute

The CPU performs the required operation.

4. Store

The result is saved when necessary.

Advantages

  • Simple design
  • Flexible operation
  • Supports stored-program systems
  • Widely implemented

Disadvantages

  • Data and instructions share the same memory path.
  • Shared access can create performance bottlenecks.

19. Operating System Architecture

An operating system (OS) provides the interface between computer hardware and users. It manages system resources and ensures that applications function properly.

Process Management

Controls running programs and allocates CPU time.

Memory Management

Allocates and manages memory used by programs.

File Management

Organizes files and folders on storage devices.

Device Management

Controls hardware devices through drivers.

Security Management

Helps protect system resources and user information.

User Interface

Allows users to interact with the computer system.

Examples of Operating Systems

Microsoft Windows, macOS, Linux, Android, and iOS.

20. System Performance Factors

Computer performance refers to how efficiently a computer system completes tasks and processes information.

CPU Speed

Influences how quickly the processor executes instructions.

RAM Capacity

Affects how many applications and tasks can run smoothly.

Storage Type

SSD storage generally provides faster data access than HDD storage.

Graphics Processing

Supports graphics-intensive tasks such as video editing and gaming.

Cooling System

Helps maintain safe operating temperatures and stable performance.

Software Optimization

Efficient software helps computer resources work effectively.

21. Modern Trends in Computer Systems

Modern computer systems continue to develop as new technologies provide faster processing, improved connectivity, and more intelligent services.

Artificial Intelligence (AI)

Enables computer systems to perform tasks that normally require human intelligence, such as recognizing patterns and understanding language.

Internet of Things (IoT)

Connects physical devices to the Internet so they can collect and exchange information.

Edge Computing

Processes data closer to where it is generated instead of sending everything to a distant server.

Virtualization

Allows multiple virtual computing environments to operate on a single physical machine.

Quantum Computing

Uses principles of quantum mechanics to explore new approaches to complex computation.

Glossary

Computer Architecture

The design and organization of computer components and how they work together.

Computer Platform

The hardware and software environment where applications operate.

CPU

Central Processing Unit; executes instructions and processes data.

Hardware

The physical components of a computer system.

Software

Programs and instructions that direct computer operations.

RAM

Random Access Memory; temporary and volatile computer memory.

ROM

Read-Only Memory; non-volatile memory used to store important instructions.

Operating System

System software that manages hardware and software resources.

Server

A computer or software system that provides services to other computers.

Von Neumann Architecture

A computer design model that stores instructions and data in the same memory.

Virtualization

Technology that creates virtual computing environments on physical hardware.

IoT

Internet of Things; a network of physical devices connected to the Internet.
