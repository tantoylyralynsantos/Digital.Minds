CHAPTER 03

HTML Structure and Semantic Elements

Learn how to organize webpage content using meaningful HTML elements and understand their importance in web development.

Introduction

Semantic HTML is an important part of web development. It helps developers create well-organized webpages by using HTML elements that describe the meaning of their content.

In this lesson, you will learn about semantic HTML, common semantic elements, their purposes, and how they improve accessibility, search engine optimization, and website maintenance.

Learning Goals

  • Understand what Semantic HTML is.
  • Learn common semantic elements and their purposes.
  • Explore the benefits of Semantic HTML for accessibility, SEO, and maintainability.
  • Build a webpage using semantic HTML.

1. What is Semantic HTML?

Semantic HTML uses meaningful tags that describe the content they enclose. These tags help developers and browsers understand the structure and meaning of a webpage.

Instead of using generic elements for every part of a webpage, semantic HTML provides specific elements that describe the purpose of each content section.

Remember!

Semantic elements describe the meaning of the content, not just how the content looks on the webpage.

2. Semantic vs. Non-Semantic Elements

HTML elements can be classified as semantic or non-semantic depending on whether they describe the meaning of their content.

Non-Semantic Elements

Non-semantic elements do not clearly describe the meaning of their content. They are commonly used as general containers.

  • <div>
  • <span>

Semantic Elements

Semantic elements clearly describe the purpose and meaning of the content they contain.

  • <header>
  • <article>
  • <footer>

Example

A <div> can group content without describing its purpose, while a <header> identifies the header section of a webpage.

3. Benefits of Semantic HTML

Using semantic HTML provides several benefits when developing and maintaining websites.

Accessibility

Semantic elements help screen readers and assistive technologies understand webpage content.

Search Engine Optimization (SEO)

Well-structured HTML helps search engines understand the organization and content of a webpage.

Maintainability

Semantic HTML makes code more readable, organized, and easier for developers to maintain.

Future-Proofing

Using meaningful HTML elements supports structured webpage development.

4. Common Semantic HTML Elements

Semantic HTML provides different elements that help organize the structure and content of a webpage.

<header> — Header Element

Defines the header section of a webpage or a content area. It commonly contains titles, logos, and introductory content.

<nav> — Navigation Element

Represents a section containing navigation links used to move between pages or sections of a website.

<main> — Main Element

Represents the main content of a webpage.

<section> — Section Element

Groups related content together into a meaningful section.

<article> — Article Element

Represents independent and self-contained content, such as an article, blog post, or news story.

<aside> — Aside Element

Represents related content that is separate from the main content, such as a sidebar or related links.

<footer> — Footer Element

Defines the footer section of a webpage. It commonly contains contact information or other closing information.

6. Hands-On Activity: Building a Semantic Webpage

In this activity, you will create a simple webpage using semantic HTML elements.

Activity Requirements

  • Create a header containing the webpage title.
  • Add a navigation section with links.
  • Create a main content section.
  • Add an article inside the main content.
  • Create a sidebar using the aside element.
  • Add a footer containing contact information.

Steps to Follow

  1. Open your code editor, such as Visual Studio Code.
  2. Create a new HTML file.
  3. Organize the webpage using semantic HTML elements.
  4. Add sample content to each element.
  5. Save the file and open it in a web browser.
  6. Check whether the webpage is properly structured.

7. Best Practices for Semantic HTML

Follow these practices when creating webpages using semantic HTML:

  • Use semantic elements whenever they are appropriate.
  • Avoid overusing <div> and <span> when a more meaningful element is available.
  • Organize webpage content into clear sections.
  • Use elements according to their intended purpose.
  • Write readable and maintainable HTML code.

8. Lesson Summary

Semantic HTML uses meaningful elements to describe the structure and content of a webpage.

Common semantic elements include header, nav, main, section, article, aside, and footer. Each element serves a specific purpose in organizing webpage content.

Key Takeaway

Semantic HTML helps developers create webpages that are more organized, accessible, readable, and easier to maintain.

CHAPTER 03 VOCABULARY

Glossary of Terms

This glossary contains important terms and definitions discussed in Lesson 3: HTML Structure and Semantic Elements.

1. HTML

HyperText Markup Language. The standard markup language used to structure webpage content.

2. Semantic HTML

The use of meaningful HTML elements that describe the purpose and meaning of webpage content.

3. Non-Semantic Elements

HTML elements that do not clearly describe the meaning of their content, such as div and span.

4. Element

A component of an HTML document, usually made up of a start tag, content, and an end tag.

5. Tag

A markup instruction written inside angle brackets that identifies an HTML element.

6. Header

An HTML element that represents introductory content or a group of navigational aids.

7. Navigation

The section of a webpage that contains links for navigating between pages or sections.

8. Main Element

An element that represents the dominant content of a webpage.

9. Section

An HTML element used to group related content into a meaningful section.

10. Article

An element representing independent and self-contained content.

11. Aside

An element representing content related to the main content but separate from it.

12. Footer

An element that represents footer information for a webpage or section.

13. Accessibility

The practice of making websites usable by people with different abilities.

14. SEO

Search Engine Optimization. Practices that help search engines understand webpage content.

15. Screen Reader

Assistive technology that reads digital content aloud or presents it through another output.

16. Maintainability

The ease with which developers can understand, update, and manage website code.

17. DOM

Document Object Model. A structured representation of an HTML document that scripts can access.

18. Webpage Structure

The organization of content and elements within an HTML document.

Learning Tip

Review these terms to better understand how semantic elements organize webpage content and improve accessibility and maintainability.
