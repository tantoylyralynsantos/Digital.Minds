CHAPTER 04

CSS - Styling and Layout

Learn how Cascading Style Sheets (CSS) transform basic HTML documents into attractive, organized, responsive, and user-friendly websites.

Introduction

Cascading Style Sheets (CSS) is a stylesheet language used to describe how HTML elements should appear on a webpage. It controls the colors, fonts, spacing, layouts, backgrounds, and overall visual presentation of a website.

CSS works together with HTML to create organized and attractive websites. While HTML provides the structure and content, CSS controls the appearance and layout of those elements.

Learning Objectives

At the end of this lesson, students should be able to:

  • Explain the basic concepts and functions of CSS.
  • Identify selectors, properties, and values.
  • Apply text styling and CSS box model properties.
  • Understand positioning, display, Flexbox, and Grid.
  • Create responsive layouts using media queries.
  • Identify advanced CSS concepts and frameworks.
  • Apply CSS best practices when developing websites.

1. CSS Basics

CSS uses rules to apply styles to HTML elements. A CSS rule contains a selector and a declaration block with properties and values.

Basic CSS Syntax

p {
    color: blue;
    font-size: 16px;
}

In this example, p is the selector, color and font-size are properties, and blue and 16px are their values.

Basic CSS Selectors

Selector Example Purpose
Type Selector div { } Selects all elements with the specified tag.
Class Selector .container { } Selects elements with a specific class.
ID Selector #header { } Selects the element with a specific ID.

CSS Combinators

Combinators describe relationships between selectors.

  • Descendant Selector: div p selects paragraph elements inside a div.
  • Child Selector: div > p selects direct paragraph children of a div.
  • Adjacent Sibling: h1 + p selects the paragraph immediately after an h1.
  • General Sibling: h1 ~ p selects paragraph siblings following an h1.

Pseudo-Classes and Pseudo-Elements

Pseudo-Classes

Define a special state of an element, such as when a user hovers over or focuses on it. 

a:hover {
    color: blue;
}

Pseudo-Elements

Style a specific part of an element, such as the first letter or first line. 

p::first-letter {
    font-size: 2em;
}

2. Styling Text and Fonts

CSS provides different properties for controlling the appearance and readability of text on a webpage.

Font Properties

font-family

Specifies the typeface or font used for text.

p {
    font-family: Arial, sans-serif;
}

font-size

Controls the size of the text using units such as px, em, rem, or vw.

p {
    font-size: 16px;
}

font-weight

Controls the thickness or boldness of text.

p {
    font-weight: bold;
}

line-height

Controls the vertical space between lines of text.

p {
    line-height: 1.6;
}

Text Properties

  • color: Changes the color of text.
  • text-align: Aligns text to the left, right, center, or justified.
  • text-transform: Changes text to uppercase, lowercase, or capitalize.
  • text-decoration: Adds underline, overline, or line-through effects.

Example of Text Styling

h1 {
    color: #07376f;
    text-align: center;
    text-transform: uppercase;
}

p {
    font-size: 16px;
    line-height: 1.6;
}

3. CSS Box Model

The CSS Box Model explains how every HTML element is displayed as a rectangular box. It consists of four main parts: content, padding, border, and margin.

MARGIN
BORDER
PADDING
CONTENT

Content

The actual information inside the element, such as text or images.

Padding

The space between the content and the border.

Border

The boundary surrounding the padding and content.

Margin

The space outside the border that separates elements.

Box Model Properties

div {
    width: 200px;
    height: 150px;
    padding: 20px;
    border: 2px solid black;
    margin: 10px;
    box-sizing: border-box;
}

Remember!

The box-sizing: border-box; property includes padding and border within the specified width and height of an element.

4. Positioning and Display

CSS Positioning

The position property determines how an element is placed within a webpage.

Static

The default position. Elements follow the normal document flow.

div {
    position: static;
}

Relative

Positions an element relative to its normal position.

div {
    position: relative;
    top: 10px;
    left: 20px;
}

Absolute

Positions an element relative to its nearest positioned ancestor.

div {
    position: absolute;
    top: 50px;
    left: 50px;
}

Fixed

Positions an element relative to the browser window, even while scrolling.

div {
    position: fixed;
    bottom: 0;
    right: 0;
}

Sticky

Allows an element to stick to a specified position while scrolling.

div {
    position: sticky;
    top: 0;
}

CSS Display Property

Block

Takes up the full available width and starts on a new line.

div {
    display: block;
}

Inline

Takes only the space needed and stays within the same line.

span {
    display: inline;
}

Inline-Block

Stays inline while allowing width and height to be controlled.

div {
    display: inline-block;
}

Flex and Grid

Modern layout systems for arranging webpage elements.

.container {
    display: flex;
}

5. Flexbox (Flexible Box Layout)

Flexbox is a one-dimensional CSS layout model used to arrange and align items in a row or column. It provides flexible control over spacing, alignment, and item sizing.

Flexbox Container Properties

display: flex

Activates Flexbox on a container.

.container {
    display: flex;
}

flex-direction

Determines whether items are arranged in a row or column.

.container {
    display: flex;
    flex-direction: row;
}

justify-content

Controls the alignment and distribution of items along the main axis.

.container {
    justify-content: space-between;
}

align-items

Aligns items along the cross axis.

.container {
    align-items: center;
}

flex-wrap

Allows items to move to another line when space is limited.

.container {
    flex-wrap: wrap;
}

Flexbox Item Properties

  • flex-grow: Determines how much an item can grow.
  • flex-shrink: Determines how much an item can shrink.
  • flex-basis: Sets the initial size of an item.
  • align-self: Controls the alignment of one individual item.
  • order: Changes the visual order of flex items.

6. CSS Grid Layout

CSS Grid is a two-dimensional layout system that allows developers to arrange elements in rows and columns at the same time.

Important Grid Properties

grid-template-columns

Defines the number and size of columns.

.container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
}

grid-template-rows

Defines the size of grid rows.

.container {
    grid-template-rows: auto 100px;
}

gap

Controls the spacing between rows and columns.

.container {
    display: grid;
    gap: 10px;
}

grid-template-areas

Assigns named areas to parts of a grid layout.

.container {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

Grid Item Properties

  • grid-column: Specifies how many columns an item occupies.
  • grid-row: Specifies how many rows an item occupies.

7. Responsive Web Design

Responsive Web Design is an approach to creating websites that adjust their appearance and layout depending on the screen size and device being used.

Media Queries

Media queries apply different CSS styles depending on screen width, resolution, or orientation. 

@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

Relative Units

Relative units allow elements to adjust based on their parent or viewport dimensions.

em

Relative to the font size of the element's context.

rem

Relative to the root element's font size.

%

Relative to the size of the containing element.

vw and vh

Relative to the viewport width and height.

Why is Responsive Design Important?

  • Improves the user experience on mobile devices.
  • Makes websites accessible on different screen sizes.
  • Provides flexible and adaptable layouts.
  • Reduces the need to maintain separate desktop and mobile websites.

8. Advanced CSS Concepts

CSS Transitions

Transitions create smooth changes when CSS properties change from one value to another. 

button {
    background-color: blue;
    transition: background-color 0.3s ease;
}

button:hover {
    background-color: darkblue;
}

CSS Animations

Animations allow elements to change styles through keyframes over a specified period. 

@keyframes slideIn {
    from {
        transform: translateX(-100%);
    }

    to {
        transform: translateX(0);
    }
}

div {
    animation: slideIn 1s forwards;
}

CSS Variables

CSS custom properties allow developers to store reusable values such as colors and spacing. 

:root {
    --main-color: #3498db;
}

div {
    background-color: var(--main-color);
}

Other Advanced CSS Features

  • calc(): Performs calculations for CSS property values.
  • clamp(): Sets a flexible value with minimum and maximum limits.
  • min() and max(): Return the smallest or largest value from a group of values.
  • Scroll Snap: Helps scrolling stop at defined positions.
  • CSS Filters: Apply visual effects such as blur and brightness.
  • Clip Path: Creates custom shapes by clipping parts of an element.
  • CSS Logical Properties: Adapt spacing to writing direction and layout.

9. CSS Best Practices and Optimization

CSS best practices help developers create organized, maintainable, accessible, and efficient stylesheets.

Organize Your Code

Use comments and sections to make stylesheets easier to understand.

Use Shorthand Properties

Combine related properties when appropriate to keep CSS concise.

Remove Unused CSS

Reduce unnecessary styles to improve stylesheet efficiency.

Use Consistent Naming

Follow naming methodologies such as BEM to organize CSS classes.

Accessibility

Use readable color contrast and visible keyboard focus states.

Reduced Motion

Respect users who prefer fewer animations and motion effects.

Example: Accessible Focus State

a:focus {
    outline: 2px solid blue;
}

10. CSS Frameworks: Bootstrap and Tailwind CSS

CSS frameworks provide predefined styles, utilities, and components that help developers build websites more efficiently.

Bootstrap

Bootstrap is an open-source CSS framework that provides a responsive grid system, reusable components, and utility classes.

Features of Bootstrap

  • Responsive grid system.
  • Pre-built buttons, forms, cards, and modals.
  • Mobile-first design.
  • Customizable styles and components.
<link
href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
rel="stylesheet">

<div class="container">
    <h1 class="text-center">
        Hello, Bootstrap!
    </h1>
</div>

Tailwind CSS

Tailwind CSS is a utility-first framework that allows developers to style elements directly through predefined utility classes.

Features of Tailwind CSS

  • Utility-first approach.
  • Highly customizable design.
  • Responsive utility classes.
  • Consistent spacing and typography.
<div class="bg-blue-500 p-4 text-white">
    Hello, Tailwind!
</div>

Bootstrap vs. Tailwind CSS

Category Bootstrap Tailwind CSS
Approach Component-based framework Utility-first framework
Design Provides predefined components Builds custom designs using utility classes
Customization Customizable through its styling system Highly customizable through configuration and utilities
Best Use Quick development using ready-made components Custom layouts and designs

12. Learning Activities

Apply what you have learned through the following tasks.

Activity 1: CSS Selector Identification

Instructions: Identify the type of CSS selector used in each example.

  1. p { color: blue; }
  2. .header { background: navy; }
  3. #footer { text-align: center; }
  4. a:hover { color: red; }
  5. div p { font-size: 16px; }

Task: Identify whether each example uses a type, class, ID, pseudo-class, or descendant selector.

Activity 2: Box Model Analysis

Examine the following CSS code and identify the content, padding, border, and margin values. 

.card {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
    margin: 15px;
}

Task: Explain the purpose of each box model property and how it affects the card layout.

Activity 3: Flexbox and Grid Comparison

Instructions: Answer the following questions.

  1. What is the main purpose of Flexbox?
  2. How is CSS Grid different from Flexbox?
  3. When would you use Flexbox in a navigation bar?
  4. When would you use Grid to arrange cards?
  5. Give one example of a website layout that uses both.

Hands-On Exercise: Create a Responsive Webpage

Objective: Create a simple responsive webpage using HTML and CSS.

Requirements:

  1. Create a webpage with a header and navigation bar.
  2. Add a main content section with three cards.
  3. Use CSS Grid or Flexbox to arrange the cards.
  4. Apply colors, fonts, padding, margins, and borders.
  5. Add a media query for smaller screens.
  6. Test the webpage on desktop and mobile screen sizes.

Expected Output: A clean and responsive webpage that adjusts its layout based on screen size.
