Chapter 6: DOM Manipulation and JavaScript Events

Understanding how JavaScript interacts with HTML documents and responds to user actions.

Introduction

A website becomes interactive when JavaScript can access and modify the elements of an HTML document. The Document Object Model (DOM) provides a structured representation of a web page, allowing JavaScript to select elements, change their content, update styles, and respond to user actions.

This chapter introduces the DOM, its tree structure, element selection methods, document modification, and JavaScript events. These concepts are important when developing dynamic and interactive websites.

Learning Focus: Use JavaScript to access HTML elements, change page content, and handle events such as clicks, keyboard input, and form submissions.

1. Document Object Model (DOM)

The Document Object Model (DOM) is a programming interface that represents an HTML document as a structured collection of objects. It allows programming languages such as JavaScript to access and manipulate the content, structure, and styles of a web page.

When a browser loads an HTML document, it creates a DOM representation. Each HTML element becomes an object that JavaScript can work with.

Example: Accessing the DOM

<h1 id="heading">Hello, Student!</h1>

<script>
    document.getElementById("heading").style.color = "blue";
</script>

In this example, JavaScript finds the element with the ID heading and changes its text color to blue.

2. DOM Tree and Nodes

The DOM organizes an HTML document in a tree-like structure. Elements are connected through parent, child, and sibling relationships.

Common DOM Node Types

  • Document Node: Represents the entire HTML document.
  • Element Node: Represents HTML elements such as h1, p, div, and body.
  • Text Node: Contains the text inside an element.
  • Attribute Node: Represents attributes such as id, class, and href.

Parent, Child, and Sibling Relationships

  • Parent: An element that contains another element.
  • Child: An element located inside another element.
  • Sibling: Elements that share the same parent.
  • First Child: The first child node of a parent.
  • Last Child: The last child node of a parent.
const parent = document.getElementById("container");

console.log(parent.children);
console.log(parent.firstElementChild);
console.log(parent.lastElementChild);

3. DOM Collections

DOM collections are groups of nodes or elements returned by certain DOM properties and methods. They allow developers to work with multiple elements.

  • childNodes – Returns all child nodes, including text nodes.
  • children – Returns the child elements only.
  • firstChild – Returns the first child node.
  • lastChild – Returns the last child node.
  • parentElement – Returns the parent element.

Example

const list = document.getElementById("myList");

console.log(list.children);
console.log(list.childNodes);
console.log(list.firstElementChild);
console.log(list.lastElementChild);
Remember: The childNodes property may include text nodes created by spaces and line breaks, while children returns only HTML elements.

4. Selecting DOM Elements

JavaScript provides different methods for finding HTML elements. Selecting the correct element is the first step before changing its content or behavior.

Common Selection Methods

MethodPurpose
getElementById()Selects an element using its ID.
getElementsByClassName()Selects elements using a class name.
getElementsByTagName()Selects elements using a tag name.
querySelector()Selects the first element matching a CSS selector.
querySelectorAll()Selects all elements matching a CSS selector.

Examples

// Select by ID
const title = document.getElementById("mainTitle");

// Select by class
const cards = document.getElementsByClassName("card");

// Select by tag
const paragraphs = document.getElementsByTagName("p");

// Select the first matching CSS selector
const firstCard = document.querySelector(".card");

// Select all matching CSS selectors
const allCards = document.querySelectorAll(".card");
Tip: querySelector() and querySelectorAll() support CSS selector syntax, making them flexible for selecting elements.

5. Modifying HTML Elements

JavaScript can modify the content and structure of a web page after it has loaded. Developers can change text, update HTML, create new elements, and remove existing elements.

Changing Text Content

document.getElementById("message").textContent =
    "Welcome to WEBTECH LEARN!";

Changing HTML Content

document.getElementById("content").innerHTML =
    "<strong>Hello, BSIT 3!</strong>";

Creating and Adding Elements

const newParagraph = document.createElement("p");

newParagraph.textContent = "This is a new paragraph.";

document.body.appendChild(newParagraph);

Removing an Element

const item = document.getElementById("oldItem");

item.remove();

Adding and Removing Classes

const box = document.getElementById("myBox");

box.classList.add("active");
box.classList.remove("active");
box.classList.toggle("active");

6. Styling DOM Elements

JavaScript can change the CSS styles of an element through its style property. It can also add or remove CSS classes.

Using the style Property

const heading = document.getElementById("heading");

heading.style.color = "blue";
heading.style.backgroundColor = "lightgray";
heading.style.fontSize = "30px";

Using classList

const box = document.querySelector(".box");

box.classList.add("highlight");
box.classList.remove("highlight");
box.classList.toggle("highlight");

7. JavaScript Events

An event is an action or occurrence detected by the browser. JavaScript can respond to these events to make a web page interactive.

Common JavaScript Events

  • click – Occurs when an element is clicked.
  • dblclick – Occurs when an element is double-clicked.
  • mouseover – Occurs when the pointer moves over an element.
  • mouseout – Occurs when the pointer leaves an element.
  • keydown – Occurs when a keyboard key is pressed.
  • keyup – Occurs when a keyboard key is released.
  • submit – Occurs when a form is submitted.
  • change – Occurs when the value of an input changes.
  • load – Occurs when a page or resource finishes loading.

Example: Click Event

const button = document.getElementById("myButton");

button.onclick = function() {
    alert("Button clicked!");
};

8. Event Listeners and Event Objects

The addEventListener() method attaches an event handler to an element. It is a recommended way to handle events because multiple listeners can be attached to the same element.

Syntax

element.addEventListener("event", function);

Example

const button = document.getElementById("clickButton");

button.addEventListener("click", function() {
    alert("You clicked the button!");
});

Using the Event Object

The event object contains information about the event that occurred. It is commonly represented by the parameter event or e. 

document.addEventListener("click", function(event) {
    console.log("Event type:", event.type);
    console.log("Clicked element:", event.target);
});

Removing an Event Listener

function showMessage() {
    alert("Hello!");
}

button.addEventListener("click", showMessage);

// Remove the same listener
button.removeEventListener("click", showMessage);

9. dispatchEvent() and CustomEvent

JavaScript can trigger events programmatically using dispatchEvent(). Developers can also create their own events using the CustomEvent constructor.

Creating and Dispatching a Custom Event

const messageEvent = new CustomEvent("messageReady", {
    detail: {
        message: "A custom event was triggered!"
    }
});

document.addEventListener("messageReady", function(event) {
    console.log(event.detail.message);
});

document.dispatchEvent(messageEvent);

In this example, a custom event named messageReady is created and dispatched. The detail property carries additional information.

12. Glossary

DOM (Document Object Model)
A programming interface that represents an HTML document as objects.
DOM Tree
A hierarchical structure showing the relationships between document nodes.
Node
A basic unit in the DOM, such as a document, element, or text node.
Element
An HTML component represented as an object in the DOM.
Selector
A method or pattern used to find HTML elements.
Event
An action or occurrence detected by the browser.
Event Listener
A function registered to respond when a specific event occurs.
Event Object
An object containing information about an event.
addEventListener()
A method used to attach an event handler to an element.
dispatchEvent()
A method used to trigger an event programmatically.
CustomEvent
An event created by a developer for a specific application purpose.
