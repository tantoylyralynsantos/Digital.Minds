Chapter 7: Forms and Input Validation

Learn how to collect, check, and validate user information using HTML forms and JavaScript.

Introduction

Forms are important parts of interactive websites. They allow users to submit information such as names, email addresses, passwords, contact numbers, and other details.

Form validation is the process of checking whether the information entered by a user follows the required rules before it is processed. JavaScript can validate information in the browser and provide immediate feedback when an input is missing or incorrect.

Learning Objectives:
  • Understand the purpose of HTML forms and form validation.
  • Handle form submission using JavaScript events.
  • Validate text, email, phone, and password inputs.
  • Use regular expressions to check input formats.
  • Display error messages and validate inputs in real time.
  • Build a simple registration form with JavaScript validation.

1. Why Does Form Validation Matter?

Forms Are Everywhere

Websites use forms for login pages, registration, checkout, feedback, contact pages, online bookings, and search features. Developers need to ensure that the information submitted by users is complete and follows the expected format.

Better User Experience

Validation provides helpful feedback when users make mistakes. Instead of waiting for a page to reload, users can immediately see messages such as "Email is required" or "Password is too short."

Data Quality and Security

Validation helps prevent incomplete or incorrectly formatted information from being submitted. However, client-side validation can be bypassed, so important information must also be validated on the server.

Important: Client-side validation improves user experience, but it is not a replacement for server-side validation.

2. The Form Submit Event

The submit event occurs when a user submits a form by clicking the submit button or pressing Enter. JavaScript can listen for this event and check the entered information before continuing.

Using preventDefault()

The preventDefault() method stops the browser's default form submission behavior. This allows JavaScript to validate the information first. 

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
    event.preventDefault();

    const name = document.getElementById("name").value.trim();

    if (name === "") {
        console.log("Name is required.");
    } else {
        console.log("Form is ready!");
    }
});

The trim() method removes unnecessary spaces at the beginning and end of a text value.

3. Basic Validation Checks

JavaScript can perform different checks depending on the input field.

Minimum LengthChecks the minimum number of characters.value.length < 8
Maximum LengthChecks the maximum number of characters.value.length > 50
Number RangeChecks if a number is within a range.age < 13

const password = document.getElementById("password").value;

if (password.length < 8) {
    console.log("Password must have at least 8 characters.");
}

4. Regular Expressions (Regex) for Validation

A regular expression, also called Regex, is a pattern used to check whether a string follows a specific format. It is useful for validating email addresses, phone numbers, names, and passwords.

Email Pattern

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

console.log(emailRegex.test("student@example.com")); // true
console.log(emailRegex.test("student@")); // false

Phone Number Pattern

const phoneRegex = /^\d{10}$/;

console.log(phoneRegex.test("9876543210")); // true
console.log(phoneRegex.test("12345")); // false

This example checks for exactly 10 digits. Actual phone number rules depend on the country and application requirements.

Password Pattern

const passwordRegex =
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/;

console.log(passwordRegex.test("Student123")); // true
console.log(passwordRegex.test("student123")); // false

Name Pattern

const nameRegex = /^[A-Za-z\s]+$/;

console.log(nameRegex.test("Maria Santos")); // true
console.log(nameRegex.test("Maria123")); // false
Regex Tip: The test() method returns true when the input matches the pattern and false when it does not.

5. Showing Error Messages Dynamically

Instead of displaying repeated alert boxes, developers can show error messages directly below the input fields. This makes forms easier to understand and use. 

function showError(input, message) {
    const error = document.createElement("div");

    error.className = "error";
    error.textContent = message;

    input.parentNode.appendChild(error);
}

Developers can also use CSS classes to highlight invalid fields with red borders and valid fields with green borders. 

input.classList.add("invalid");
input.classList.remove("valid");

input.classList.add("valid");
input.classList.remove("invalid");

6. Real-Time Validation

Real-time validation checks information while the user is typing. The input event is commonly used for text fields. It allows users to receive immediate feedback without submitting the entire form. 

const emailInput = document.getElementById("email");

emailInput.addEventListener("input", function() {
    const email = emailInput.value.trim();

    if (email === "") {
        console.log("Email is required.");
    } else if (!emailRegex.test(email)) {
        console.log("Enter a valid email.");
    } else {
        console.log("Valid email.");
    }
});

Common Input Events

  • input: Fires when the value of an input changes.
  • change: Fires when a value is changed and committed.
  • focus: Fires when an input receives focus.
  • blur: Fires when an input loses focus.

7. Handling Checkboxes, Radio Buttons, and Select

Checkboxes

The checked property returns a Boolean value indicating whether a checkbox is selected. 

const agreement = document.getElementById("agree");

console.log(agreement.checked);

Radio Buttons

Radio buttons allow users to choose one option from a group. 

const selected = document.querySelector(
    'input[name="course"]:checked'
);

if (selected) {
    console.log(selected.value);
}

Select Dropdown

A select element allows users to choose an option from a dropdown list. 

const city = document.getElementById("city");

console.log(city.value);

console.log(city.options[city.selectedIndex].text);

8. Password Strength Checker

A password strength checker evaluates a password based on requirements such as length, uppercase letters, lowercase letters, numbers, and special characters.

Weak: Few requirements are met.
Medium: Several requirements are met.
Strong: Most or all requirements are met.

Example

function checkStrength(password) {
    let score = 0;

    if (password.length >= 8) score++;
    if (password.length >= 12) score++;
    if (/[a-z]/.test(password)) score++;
    if (/[A-Z]/.test(password)) score++;
    if (/\d/.test(password)) score++;
    if (/[^A-Za-z0-9]/.test(password)) score++;

    if (score <= 2) return "Weak";
    if (score <= 4) return "Medium";

    return "Strong";
}

9. Enabling and Disabling the Submit Button

A submit button can remain disabled until all required fields pass validation. This helps prevent incomplete forms from being submitted accidentally. 

function checkFormValidity() {
    const nameValid = nameInput.value.trim().length >= 2;
    const emailValid = emailRegex.test(emailInput.value);

    submitButton.disabled = !(nameValid && emailValid);
}
Remember: Always validate the form again when the user submits it. Do not rely only on a disabled button.

15. Glossary

HTML Form
An HTML structure used to collect information from users.
Form Validation
The process of checking whether user input follows required rules.
Client-side Validation
Validation performed in the user's browser before data is sent to a server.
Server-side Validation
Validation performed by the server after receiving submitted data.
Submit Event
An event that occurs when a form is submitted.
preventDefault()
A method that prevents the browser's default action.
Regular Expression (Regex)
A pattern used to match and validate strings.
Real-Time Validation
Checking user input while the user is typing or changing a field.
Checkbox
A form control that allows a user to select or deselect an option.
Radio Button
A form control used to select one option from a group.
Password Strength
An estimate of how well a password meets security requirements.
