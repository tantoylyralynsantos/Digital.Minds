Identify the Semantic Elements

  2. Contains navigation links.

  4. Groups related content together.

ASSESSMENT 2

Semantic or Non-Semantic?

Classify each HTML element as Semantic or Non-Semantic.

  1. <div>
  2. <header>
  3. <span>
  4. <article>
  5. <footer>
  6. <nav>
  7. <main>
Task: Group the elements into two categories: Semantic Elements and Non-Semantic Elements.
PRACTICAL ASSESSMENT

Build a Simple Semantic Webpage

Apply what you have learned by creating a webpage using semantic HTML elements.

Instructions

  1. Create a header with a webpage title.
  2. Add a navigation section with at least three links.
  3. Create a main section containing an article.
  4. Add an aside section with related links.
  5. Create a footer with contact information.
Expected Output: Save your work as semantic.html and test it using a web browser.
REQUIRED HTML STRUCTURE 
<header>
    <h1>My Webpage</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
</nav>

<main>
    <article>
        <h2>My Article</h2>
        <p>Article content goes here.</p>
    </article>

    <aside>
        Related information
    </aside>
</main>

<footer>
    Contact Information
</footer>
